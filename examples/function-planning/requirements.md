# Function planning example requirements

This is an illustrative local note application scope for demonstrating the planning tools. No note application is implemented by this toolbox.

## R1: Save a note

Accept a note with a nonempty title and body, validate it and persist it locally. Return the saved note identity. Reject a blank title without creating a partial record.

## R2: List notes

Return the titles and identities of saved notes. An empty store returns an empty collection. Listing notes does not create or modify records.
