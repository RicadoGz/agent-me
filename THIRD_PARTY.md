# Third Party Components

This repository combines selected instructions and agent definitions from the following projects. Their original licenses and notices remain with the copied files.

1. **Superpowers**, [obra/superpowers](https://github.com/obra/superpowers), MIT. Selected development skills and supporting files are under `skills/software-development/components/superpowers`.

2. **Matt Pocock skills**, [mattpocock/skills](https://github.com/mattpocock/skills), MIT. The grilling and code review skills are under `skills/software-development/components/mattpocock`.

3. **Playwright**, [microsoft/playwright](https://github.com/microsoft/playwright), Apache 2.0. The generated planner and generator definitions, license and notice are under `skills/software-development/components/playwright`.

4. **Serena**, [oraios/serena](https://github.com/oraios/serena), GPL 3.0 or later. This package includes its README and license for reference; the executable is installed separately from the official project.

See [sources.json](skills/software-development/sources.json) for the precise source revisions and hashes. The combination instructions and local setup helpers are maintained separately from the upstream snapshots.
